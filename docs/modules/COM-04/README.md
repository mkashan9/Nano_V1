# COM-04 — Text Messages, Replies, Mentions, and Reactions

Active members can chat in a community: send text, reply, mention members,
and react with emoji. Media / pins stay COM-05 / COM-06.

## Owns

- `community_messages`, `community_message_mentions`, `message_reactions`
- `list_community_messages` / `send_community_message` / `toggle_message_reaction`
- Community chat page + Open chat from hub detail

## Does not own

- Voice / photos / files → COM-05
- Pins / search / archive → COM-06
- Moderation queue → SAFE-02
