# PAR-02 manual test

1. Open **admin_web** as superadmin (fake/preview shell is fine).
2. Open **Parent guidance** in the side rail.
3. Tap **New draft** — a draft appears in the list.
4. Enter a PDF file name ending in `.pdf` (e.g. `week-guidance.pdf`) and tap
   **Attach PDF**.
5. Enter one activity tip per line and tap **Save tips**.
6. Tap **Publish** — status becomes published.
7. Confirm publish fails (snackbar) if PDF name is missing or not `.pdf`.
