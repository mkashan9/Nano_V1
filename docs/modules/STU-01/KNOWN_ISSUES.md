# STU-01 Known Issues

- No verified grade source exists yet, so every learner self-reports. School-linked grades arrive with SCH-04.
- The school context step shows the school name only when the session already carries it; a school lookup by id is deferred.

- Progress writes are not queued offline; the flow requires connectivity, matching the "offline sign-in is not allowed" rule.
