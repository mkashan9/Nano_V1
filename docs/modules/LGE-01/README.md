# LGE-01 — Weekly Leagues

Personal weekly league position on Profile. Learners join the current ISO
week; rank uses verified `game_result` XP only (never marks/attendance).

## Owns

- `league_cycles`, `league_divisions`, `league_participants`
- `join_current_league` / `my_league_status`
- Profile weekly league card

## Does not own

- Peer leaderboard UIs → LGE-02
- Challenges / rematches → LGE-03
- Promotion/relegation automation (deferred)
