# SOC-04 — Social Sharing

Share destinations for XP-06 privacy-safe cards: copy, system share sheet,
WhatsApp, and a Communities placeholder. Cards prefer the SOC-01 social
label (username when claimed).

## Owns

- Share target sheet + card preview UI
- `build_share_card` social-label preference
- WhatsApp / system share dispatch

## Does not own

- Share card payload content rules → XP-06
- Communities post pipeline → COM-01
- Bitmap image export (preview is the privacy-reviewed surface for now)
