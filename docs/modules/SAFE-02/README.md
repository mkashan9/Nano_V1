# SAFE-02 — Moderation Queue and Evidence

Platform staff review open learner reports, view privacy-safe evidence
(access audited), and close cases with dismiss / resolve / warn / suspend.

## Owns

- Moderation list / claim / resolve RPCs
- `moderation_evidence_access` audit trail
- Admin Moderation → User reports queue UI

## Does not own

- Learner submit/block flow → SAFE-01
- Rate limits / link rules → SAFE-03
- Media asset review → MED-05 (same Moderation hub tab)
