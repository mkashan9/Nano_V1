# SAFE-02 manual test

1. Open admin_web as superadmin → Moderation → **User reports**.
2. Select an open report (submit one from student_app if the queue is empty).
3. Confirm evidence labels show; enter a resolution note.
4. Dismiss or Resolve; confirm the queue updates.
5. Optional: Suspend with a note; confirm the reported profile is suspended (ADM-03).
