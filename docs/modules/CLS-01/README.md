# CLS-01 — Teacher Classroom Announcements

Teachers create draft (or publish-now) announcements scoped to active
`teacher_assignments`.

## Owns

- `classroom_items`
- `teacher_classroom_list` / `create` / `update`
- Classroom nav destination UI

## Does not own

- Attachments → CLS-02
- Schedule / expiry / acknowledgements → CLS-03
- Student Flex classroom feed → FLX-04
