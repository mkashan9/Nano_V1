# XP-05 decisions

## UTC days, not local clocks

Streak days follow the server's UTC calendar so a learner near midnight does
not invent an extra day by changing device timezone.

## Pause is soft and kind

Handbook: broken streak messaging is gentle. Missing a day zeroes the current
count on the next read or activity, preserves longest, and offers a welcome-back
line. There is no "you broke your streak" copy.

## CMP-02 supplies the mood vocabulary

The notice reuses the calm register already designed for gentle retry / return
moments. This module does not add a new companion event; the Home banner is the
surface.
