# COM-03 — Join Requests and Invitations

Seniors can join public communities immediately, request private membership,
leave, create invite codes (owners/admins), and redeem invites.

## Owns

- `join_community` / `leave_community`
- `list_join_requests` / `respond_join_request`
- `create_community_invite` / `redeem_community_invite`
- `community_invites` table
- Join / leave / invite / redeem / request review UI on Communities hub

## Does not own

- Chat / media → COM-04+
- Ban / remove member UI (deferred)
- Platform kill switch / junior block → SAFE-04
