# IND-03 — Decisions

1. **States without payment.** Plan kinds are UI-first; `applyPlan` is fake and
   never proves a receipt (BIL-01).
2. **Map onto IND-02.** Free/trial/paid → full; grace → limited; expired →
   restricted.
3. **Calm Start trial only.** Free may offer Start free trial; no buy/urgency
   copy on Home for children.
4. **Default seed is trial.** New independent reviews start mid-trial so Home
   and Me feel complete without an extra tap.
5. **Learning survives expiry.** Expired still allows learning per handbook
   reduced-access rule.
