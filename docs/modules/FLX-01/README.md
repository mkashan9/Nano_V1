# FLX-01 — Student Flex Home

School-linked seniors get a **Flex hub** with entry cards for attendance,
marks, and classroom. Independent students never see Flex.

## Owns

- `FlexHubSummary` / `StudentFlexRepository`
- Flex tab hub UI (`FlexHomePage`)
- `/flex/*` deep-link prefix → Flex hub

## Does not own

- Attendance calendar → FLX-02
- Marks/results → FLX-03
- Classroom feed → FLX-04
- Junior Flex labels (no junior Flex tab yet)
