# SCH-05 manual test

Use a school admin on development (or preview **School** shell).

1. Open **Assignments**. Confirm workload and any uncovered subjects.
2. **Assign** a teacher to a class + subject that has a Classes map.
3. Confirm the row appears active; uncovered list updates.
4. **End** with a reason; status becomes left.
5. Assign again, then **Replace** with another teacher (if two teachers exist).
