# AUTH-03 — School Management and Superadmin Authentication

## Purpose

Admin web email/password sign-in for school management and platform superadmin, with app-scoped account kinds and shell routing.

## Deliverables

- Platform + school admin `auth.users` fixtures
- School admin profile/membership seed (`school_staff` / `school_admin`)
- `admin_web` sign-in / sign-out / blocked routes
- Bootstrap for `school_staff` and `platform` account kinds

## Owner test focus

Sign in as school admin and as platform admin; confirm correct shells; sign out.
