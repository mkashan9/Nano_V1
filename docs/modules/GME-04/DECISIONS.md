# GME-04 decisions

- Reuse eligibility before listing assets (RPC).
- UI never says “manifest”, “hash”, or “download queue” — friendly copy only.
- Games with declared assets require Save before Play.
- Empty asset lists remain immediately playable (host-only fixtures).
- Fixture “download” is an instantaneous local pin keyed by content hash.
- Process-local storage is acceptable for this slice; durable disk later.
