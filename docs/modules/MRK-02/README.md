# MRK-02 — In-App Marks Grid

Teachers enter **draft** marks for draft assessments: scored obtained marks,
absent, exempt, not submitted, and remarks.

## Owns

- `marks_entries`
- `teacher_marks_load`, `teacher_marks_save`
- Marks grid UI on Marks destination
- Dashboard `unpublished_marks_count` for draft assessments with marks

## Does not own

- Assessment create/edit → MRK-01
- Excel import → MRK-03
- Publish / correction → MRK-04
