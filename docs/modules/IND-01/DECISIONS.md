# IND-01 — Decisions

1. **Reuse senior home composition.** Independents already use senior density
   (STU-04). IND-01 fills the Flex slot rather than inventing a third home.
2. **Spotlight replaces Flex, never locks.** Empty Flex placeholders and fake
   lock UI are forbidden by the handbook; a play/learn spotlight is the fill.
3. **School updates stay school-linked.** Teacher/assembly-style latest-update
   cards are omitted for independents so Home does not feel restricted.
4. **Nav labels, not a separate catalog rewrite.** Destinations stay
   learning/games/profile; copy maps them to Home/Play/Me for independents.
5. **Entitlements deferred.** Access warnings remain notice hooks; IND-02 owns
   real independent access rules.
