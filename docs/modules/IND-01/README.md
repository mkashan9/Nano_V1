# IND-01 — Independent Student Home and Natural Navigation

## Purpose

Make the independent student shell feel complete: Home / Play / Me labels,
no Flex tab or school update cards, and a Play-next spotlight where school
learners see Flex.

## Deliverables

- `IndependentSpotlight` on `StudentHomeSummary`
- Fake home seed for independents (spotlight, no Flex / school update)
- Senior home independent composition + deep-link tap
- Nav copy: independent uses Home / Play / Me

## Does not own

- Entitlements / trial / paid gates (IND-02 / IND-03)
- School invitation linking (IND-04)
- Billing (BIL-01)

## Owner test focus

Switch to Independent (or sign in as indie) → confirm bottom nav is Home /
Play / Me with no Flex → see **Play next** → tap it → Games opens.
