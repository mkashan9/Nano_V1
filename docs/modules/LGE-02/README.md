# LGE-02 — Leaderboards

Privacy-safe weekly board for the learner’s current division and school
(or independent) pool. Snapshots are server-written; labels are first name
or “Learner” when not discoverable.

## Owns

- `leaderboard_snapshots`
- `my_league_leaderboard`
- Profile → View board page

## Does not own

- Challenges / rematches → LGE-03
- Friends boards → SOC-03
- Usernames → SOC-01
