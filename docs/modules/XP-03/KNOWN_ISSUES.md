# XP-03 known issues

**Fixture streak badge remains when live awards are empty.** Without a wired
repository Me still shows the old STU-05 fixtures, including a "7 day streak"
that XP-05 does not yet grant.

**No companion celebration on unlock.** CMP-02 has an achievement mode; this
module does not fire it yet.

**Admin cannot add definitions.** Seed only; ADM-05 owns the editor.

**Urdu titles are stored but Me currently loads English** when mapping awards
in the fake/live profile path (`fromAward(urdu: false)`). Locale-aware title
selection can follow preferences without a schema change.
