# SOC-03 — Friends Leaderboards

Weekly XP ranking among the signed-in learner and their friends. Scores come
from the current league cycle (`league_participants.week_xp`); labels use
privacy-safe social names (username when claimed).

## Owns

- `my_friends_leaderboard`
- Friends → Ranking tab

## Does not own

- Division/school boards → LGE-02
- Challenges → LGE-03
- Friend graph mutations → SOC-02
