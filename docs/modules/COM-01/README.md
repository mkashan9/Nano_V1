# COM-01 — Community Discovery

Open Communities hub for senior learners: My list, Discover/search, and
read-only detail. Create/join are deferred.

## Owns

- `communities` / `community_memberships` (read via RPCs)
- `my_communities`, `discover_public_communities`, `get_community_detail`
- Student Communities tab (replaces foundation placeholder)
- Seed public communities for browse

## Does not own

- Create community / roles → COM-02
- Join / invite / leave → COM-03
- Chat / media → COM-04+
- Entitlement / junior block → SAFE-04
