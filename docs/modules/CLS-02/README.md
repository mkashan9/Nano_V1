# CLS-02 — Classroom Materials and Attachments

Teachers attach **https links** (and optional file metadata) to draft
classroom announcements.

## Owns

- `classroom_attachments`
- `teacher_classroom_attachment_add` / `remove`
- Nested attachments in `teacher_classroom_list`
- Attachments UI on Classroom edit

## Does not own

- Binary upload worker / malware scan
- Schedule / ack → CLS-03
- Student feed → FLX-04
