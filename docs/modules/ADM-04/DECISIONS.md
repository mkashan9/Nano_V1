# ADM-04 decisions

## Catalog owns subjects and topics

QZ keeps question bank and topic quizzes. MED-05 stays on Moderation.

## Server publish gates

Topic publish requires a published parent subject version plus non-empty
`video_provider` and `video_ref`. Title is required for subjects and topics.

## Version history

Publishing archives the previous published version of the same identity so
learner history remains attached to immutable version ids.
