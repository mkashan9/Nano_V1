# ADM-04 — Learning Stack Content Administration

## Purpose

Platform staff can draft, preview, publish, and archive Learning Stack subjects
and topics from the existing Content hub without developer assistance.

## Delivered

**RPCs** — `create_subject_draft`, `publish_subject_version`,
`archive_subject_version`, `create_topic_draft`, `publish_topic_version`,
`archive_topic_version`, plus `learning_authoring` curator view.

**Catalog tab** — first tab on Content alongside Question bank and Topic quizzes.

## Deferred

Bulk import, rich media pickers, full article/PDF editors, live video provider
operations. Question bank and quiz linking remain QZ-01/QZ-02.
