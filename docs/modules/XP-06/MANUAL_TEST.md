# XP-06 manual test

Use a signed-in student on the development Supabase project.

1. Open **Me**. Confirm achievements list shows star and share actions.
2. Pin up to three achievements. Confirm a **Featured** section lists them.
3. Try a fourth pin — expect the limit hint; pins stay at three.
4. Tap **Share** on an achievement. Paste the clipboard text somewhere safe.
   Confirm it uses a first name only and has no school, email, attendance, or
   marks.
5. Complete or retake a quiz to the results screen. Tap **Share score**.
   Confirm the text has a percent and first name only (no topic/school).
6. Unfeature a pin and confirm Featured updates.
