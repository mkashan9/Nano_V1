# XP-01 known issues

**Level thresholds are still client-derived.** 250 XP per level until XP-02.

**Home missions and streak are still fixtures.** Only the XP total is live.

**Game XP is reserved but not awarded.** `game_result` exists in the rules
table for GME-05; nothing calls it yet.

**Daily cap soft-refuses.** A learner at the cap still completes work; they
just get no XP. There is no UI explaining why.
