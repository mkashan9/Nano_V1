# LGE-03 — Challenges and Rematches

Peer challenges from the weekly league board using opaque target tokens.
Settlement uses verified `game_results` scores. Friend-graph invites wait
for SOC-01.

## Owns

- `challenge_rules`, `challenges`, `challenge_results`, target tokens
- Create / respond / record score / rematch RPCs
- Board Challenge CTA + Challenges inbox

## Does not own

- Friend codes / usernames → SOC-01
- Blocks / reports → SOC-02
- Push notifications → NOT-*
