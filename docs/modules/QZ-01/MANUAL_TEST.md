# QZ-01 manual test

Run `admin_web` as Superadmin (shell switcher → Superadmin if previewing).

1. Open **Content**. Confirm the question bank lists the seeded questions
   (counting, addition, living things) with **Published** status.
2. Tap **New question**. Confirm a draft appears and can be selected.
3. Tap **Publish** on that draft. Confirm status becomes **Published** and
   **Publish** is replaced by **Retire**.
4. Confirm **Junior preview** and **Senior preview** both show the same version
   id under the stem.
5. Switch the shell to **School**. Open Content — it should stay a placeholder
   without the question bank.
6. Optional: create a draft whose stem matches "How many apples are in the
   basket if you count to five?" and confirm a duplicate warning appears.

Reply `NEXT` to approve, or `FIX: …` if authorship or preview looks wrong.
