# MRK-01 — Assessment Creation

Teachers create **draft** assessments for assigned scopes: category, name,
date, total marks, optional weight, and description.

## Owns

- `assessments` (draft creation/update)
- `teacher_assessments_list`, `teacher_assessment_create`, `teacher_assessment_update`
- Marks destination create/edit draft UI
- Dashboard `draft_assessment_count` from real drafts

## Does not own

- Marks grid entry → MRK-02
- Excel import → MRK-03
- Publish / correction → MRK-04
- Result summaries → MRK-05
