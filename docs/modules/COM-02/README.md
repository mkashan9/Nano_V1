# COM-02 — Community Creation and Roles

Seniors can create open Communities and manage member roles.
Creator becomes owner. Join/invite stays COM-03.

## Owns

- `create_community`
- `list_community_members` / `set_community_member_role`
- Create form + Manage roles UI on Communities hub

## Does not own

- Join / invite / leave → COM-03
- Chat → COM-04+
- Discovery browse → COM-01
