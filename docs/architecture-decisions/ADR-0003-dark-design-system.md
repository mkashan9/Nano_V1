# ADR-0003: Design system follows UI_reference dark worlds

## Status

Accepted

## Context

UI references for Junior and Senior use dark navy canvases with high-saturation subject tiles and purple accents.

## Decision

`nano_design_system` ships dark theme families first, with tokens extracted from those references. School branding fills approved slots only.

## Consequences

Apps look closer to mockups; light themes are not a priority for R0 student surfaces.
